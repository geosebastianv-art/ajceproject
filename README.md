# Amal Jyothi College of Engineering — Landing Page

A modern, responsive landing page concept for **Amal Jyothi College of Engineering (AJCE)**, designed to present the institution, its academic programmes, campus, achievements, student life, innovation ecosystem, and admissions in a contemporary digital experience.

## ✨ Features

- Modern premium landing page design
- Fully responsive desktop, tablet, and mobile layouts
- Real AJCE campus and event imagery
- Official AJCE branding and logo
- Smooth scrolling and section navigation
- Interactive UI elements and micro-interactions
- Animated statistics and content reveals
- Programme showcase
- Campus and facilities showcase
- Student life and innovation sections
- Achievements and institutional highlights
- Admissions call-to-action
- Optimized image assets
- Production-ready deployment with Vercel

## 🛠️ Technologies

- **Next.js**
- **React**
- **JavaScript**
- **Tailwind CSS**
- **Framer Motion**
- **Lucide React**
- **Vercel**
